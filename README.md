# Маршрут — планировщик путешествий

Адаптивное веб-приложение для подготовки к поездке: маршрут по дням, бюджет, бронирования, чек-лист и ближайшие действия — на чистом HTML, CSS и JavaScript, без фреймворков, сборщиков и внешних зависимостей.

Демо-поездка: **«Лиссабон и океан»**, 12–18 сентября, 7 дней. Все даты, суммы и бронирования — демонстрационные.

## Возможности

- **Обложка поездки** — название, даты, длительность, обратный отсчёт и декоративная линия маршрута, созданные только CSS-градиентами и встроенным SVG (без внешних изображений).
- **Темп путешествия** — переключатель «Спокойно / Насыщенно»: меняет количество событий дня, стоимости, подсказку и общий прогноз расходов.
- **Маршрут по дням** — выбор дня и список событий: город, дата, время, название, категория, стоимость, статус бронирования.
- **Бюджет** — общий бюджет, запланированная сумма, остаток, кольцевой прогресс и категории расходов.
- **Бронирования** — карточки перелёта, отеля, поезда и экскурсии с кнопкой «Подтвердить» и уведомлением (тостом).
- **Чек-лист подготовки** — категории «Документы», «Деньги», «Вещи», «Здоровье»; отметки сохраняются в `localStorage` и сбрасываются кнопкой.
- **Мобильный режим «Сегодня»** — на узких экранах акцент на текущем дне и ближайшем событии + компактная нижняя навигация «Сегодня / Маршрут / Бюджет / Подготовка».
- **Состояния интерфейса** — `loading` (карточки-скелетоны), `error` (сообщение + «Повторить»), `empty` (день без событий), `success`; сворачиваемая панель «Демо состояний» для проверки.

## Стек

- HTML5, CSS3 (custom properties, grid/flex, адаптивные брейкпоинты 1440 / 768 / 390), ванильный JavaScript.
- Никаких фреймворков, npm, сборщиков, CDN и сетевых запросов.

## Запуск

Откройте `app/index.html` в браузере — приложение работает без сервера и сборки.

## Проверка состояний

Сверните панель «Демо» (правый нижний угол): «Загрузка», «Ошибка», «Пустой день», «Готово».
